# Credit Card Fraud Detection Dashboard 🕵️‍♂️💳

This project is a Machine Learning approach to detect fraudulent credit card transactions, featuring a web-based dashboard built with Streamlit.

## Features
- Handles Severe Class Imbalance using Class Weighting.
- Compares 5 ML Models: Logistic Regression, Decision Tree, Random Forest, SVM, XGBoost.
- Interactive Streamlit Dashboard for model comparison and live predictions.

## How to Run
1. Clone the repository: `git clone [https://github.com/Pedrawms]`
2. Install requirements: `pip install -r requirements.txt`
3. Run the dashboard: `streamlit run fraud_dashboard.py`

## Dataset
The dataset used is the Credit Card Fraud Detection dataset from Kaggle. Due to size limits, it's not included in this repo. Please download it from Kaggle and place it in the root folder.
